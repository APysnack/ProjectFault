Graduate Research · 2026 In progress

Does Adding a Source Make LLM Answers More Trustworthy?

This project investigates how different types of evidence affect the factual reliability of large language model answers. Using questions from SQuAD 1.1, the study compares answers generated without evidence against answers generated with relevant, irrelevant, or conflicting information. The planned evaluation examines answer accuracy, whether answers are supported by the available evidence, and how models respond to contradictions.

Graduate Research · 2026 In progress

Using AI-Generated Images to Facilitate Social Connection

This project investigates whether AI-generated images can help strangers find common ground and start conversations. The experimental prototype uses participant survey responses to generate personalized visual artifacts that another participant interprets. The study aims to evaluate participants' enjoyment, perceived social connection, and willingness to interact again.

Senior Capstone · 2021 Computer Security

Addressing PCR Fragility in TPM 2.0 Systems

Investigated how changes to a platform's configuration, such as firmware updates, can invalidate TPM 2.0 policies protecting sealed encryption keys. Studied policy mechanisms in the TPM Software Stack and implemented a Policy OR approach in the open-source Kmyth codebase, extending sealing and unsealing functionality to accommodate multiple expected platform states.

Computer Security C TPM 2.0 Open Source
Undergraduate Research · 2021 Machine Learning

Classifying Protein Signal Peptides

Evaluated supervised machine-learning algorithms for predicting signal peptides in eukaryotic and archaeal protein sequences. Prepared datasets, trained and tested classifiers using Weka, and compared their performance using Matthews correlation coefficient (MCC).
